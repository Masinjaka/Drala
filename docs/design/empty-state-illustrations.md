# Home empty-state illustrations

Created with the built-in `image_gen` tool, using `assets/illustrations/empty_states/activities.png` as the strict style reference. Both PNGs have a transparent background and use the existing theme tint when displayed.

Assets:

- `assets/illustrations/empty_states/home_envelopes.png`
- `assets/illustrations/empty_states/home_transactions.png`

## Prompt set

Each submitted prompt consisted of the common brief below, followed by its subject paragraph. Both calls used the Activities PNG as `referenced_image_paths` and `transparent_background: true`.

Common brief:

> Create one production empty-state illustration for a budgeting mobile app, using the attached image as the STRICT visual style and design reference. Match its exact minimal rounded monoline charcoal outline style, stroke thickness relative to canvas, rounded line caps and joins, clean gently offset layered-paper geometry, lack of color and lack of fill. Monochrome dark charcoal lines only, truly transparent background, no white background, no shadows, no gradients, no text, no letters, no numbers, no sparkles or decoration. Square canvas, centered composition occupying about 70% of its width with generous transparent margins, as in the reference. It must look like a sibling drawn by the same illustrator, not a different icon family.

Envelope subject:

> Subject: an empty open budget envelope, slightly rounded corners and a subtle second offset outline sheet behind it, with a small round outlined coin overlapping its lower-right corner, echoing the exact visual arrangement of the reference calendar and clock. Use a simple central vertical notch on the coin rather than any currency letter or number. Keep the envelope interior empty and the entire illustration as sparse as the reference.

Recent-transactions subject:

> Subject: a blank transaction ledger / receipt sheet with rounded corners and a subtle second offset outline sheet behind it, two small circular bullet marks with short horizontal lines on the sheet, and a small outlined clock overlapping the lower-right corner. Closely echo the reference image's paper proportions, bullets, clock design and visual balance, but make the paper a receipt/ledger without calendar binding rings. Empty transaction history, same precise visual family.
